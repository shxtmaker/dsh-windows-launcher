# D05 · 验证测试配对与远程通道

轨道：DEV。状态以 `../execution/state.json` 为唯一真值；本任务卡不预置通过结果。

依赖：D04。默认下一建议：D06（仅建议，不在同轮自动执行）。

## 单一目标

证明 Linux 真实服务上的 cookie 与免 Cookie 两条配对通路。

## 允许改动范围

- `插件集成测试的配对 helper`
- `HTTP/HTTPS fixture`
- `脱敏网络证据采集`

## 执行步骤

1. 只从测试实例 loopback 铸造令牌，通过浏览器实际 accept。
2. 用非 loopback HTTP 和受信任测试 CA 的 HTTPS 打开远程页面，分别验证 cookie 与 pair-app device 流。
3. 测试吊销后新请求拒绝，记录控制面没有通过远程代理放开。

## 必须交付

- 两个配对场景的自动测试与脱敏 trace。

## 本任务验收

- 实际请求走 /remote；无有效设备的请求不能读取工作区。
- 日志不含原始 token/device；不以浏览器管理员 cookie 绕过配对。

## 失败与停止条件

鉴权失败先核对路径、来源和设备头；不能弱化鉴权或只用localhost通过。

本轮只完成本任务及其直接验证/局部修复。达到验收、出现具体阻断，或到达需要拆分的范围边界时，写入轮次记录与检查点并结束；不得转入下一任务。缺少 Windows 实机仅影响独立系统验收，不是跳过开发实现的理由。

## 轮末证据与恢复点

记录变更文件、实际命令/退出码/用例数、证据路径与被测候选摘要；列出未验项及所属轨道。状态为 partial/blocked 时写明已保留成果、剩余一步和解除条件；下一轮先核对工作树及进程再恢复。
