# D24 · 收敛完整 Linux 开发验证

轨道：DEV。状态以 `../execution/state.json` 为唯一真值；本任务卡不预置通过结果。

依赖：D02、D19、D20、D21、D22、D23。默认下一建议：D25（仅建议，不在同轮自动执行）。

## 单一目标

在干净Linux环境对同一候选运行完整必需开发检查。

## 允许改动范围

- `verify-portable Development profile`
- `所有开发证据汇总`
- `局部门禁修复`

## 执行步骤

1. 收敛此前已逐层纳入 Development 的检查，覆盖 L01–L11、L13 的全部必需项，以及单独判定的 L12 交叉构建；包含 Core、互操作、插件、浏览器、真实宿主和包安装。
2. 重新执行完整交叉构建；支持则必过，真实平台限制提供最小复现；一般fail不合格。
3. 核对固定用例、格式、架构、hash与证据候选一致，输出正式portable摘要。

## 必须交付

- 完整Linux报告，portableStatus与crossBuildStatus独立且无虚报。

## 本任务验收

- 所有必需开发项真实通过，零用例/跳过/notRun均失败。
- 交叉构建只接受pass或有证据的toolchainUnsupported；Windows仍notRun/pending，releaseEligible=false。

## 失败与停止条件

本任务不是第一次才写所有测试；发现大缺口拆修复任务，保持未完成，不赶工合并多任务。

本轮只完成本任务及其直接验证/局部修复。达到验收、出现具体阻断，或到达需要拆分的范围边界时，写入轮次记录与检查点并结束；不得转入下一任务。缺少 Windows 实机仅影响独立系统验收，不是跳过开发实现的理由。

## 轮末证据与恢复点

记录变更文件、实际命令/退出码/用例数、证据路径与被测候选摘要；列出未验项及所属轨道。状态为 partial/blocked 时写明已保留成果、剩余一步和解除条件；下一轮先核对工作树及进程再恢复。
