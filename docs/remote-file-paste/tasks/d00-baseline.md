## 单一目标

核对实际工作树、依赖版本和 Linux 工具条件，建立可恢复的逐轮执行状态；本任务不实施业务代码。

1. 阅读当前方案、执行规则和全部任务索引，确认最终为全家桶＋独立附加插件。
2. 只读记录 HEAD、分支、用户已有修改、SDK/Node/pnpm/PowerShell/浏览器可用性；缺失工具记录到后续环境准备任务。
