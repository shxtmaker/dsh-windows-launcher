# D15 · 局部提取远程页面生命周期

轨道：DEV。状态以 `../execution/state.json` 为唯一真值；本任务卡不预置通过结果。

依赖：D11。默认下一建议：D16（仅建议，不在同轮自动执行）。

## 单一目标

为每目标页面承载epoch、通道和取消，保持现有多标签行为。

## 允许改动范围

- `Desktop/Remote/RemotePageSession.cs`
- `RemoteWindow.xaml.cs`
- `生命周期/来源规则测试`

## 执行步骤

1. 从RemoteWindow提取WebView生命周期，UI保留标签/侧栏。
2. 导航开始即撤销旧能力；验证规范化origin与主文档来源；外部链接不继承文件能力。
3. 目标删除/吊销/退出时取消，隐藏与切标签行为按方案处理。
