# D07 · 实现并验证启动前上传承载

轨道：DEV。状态以 `../execution/state.json` 为唯一真值；本任务卡不预置通过结果。

依赖：D03、D05。默认下一建议：D08（仅建议，不在同轮自动执行）。

## 单一目标

让上游文件上传经现有 remote 通道，覆盖免 Cookie 设备头与加载顺序。

## 允许改动范围

- `插件 src/host/ 注入`
- `客户端 transport hook`
- `相关单元和真实浏览器测试`

## 执行步骤

1. host index-inject 提前设置自己拥有的 __DSH_FILE_UPLOAD__；不等异步 client apply。
2. 调用时动态 window.fetch、new Headers(init?.headers)、原 /api 路径，保留body/query/signal。
3. 验证两种加载顺序、未知 hook 冲突、HTTP 200业务失败、取消和跨源拒绝。

## 必须交付

- 生产 hook 与使用最终 bundle 的测试。

## 本任务验收

- 实际 URL只改写一次，设备头存在且不跨源泄露。
- 未知 hook 不被覆盖，addon失败不关闭配对。

保留网络 trace 定位；不能手拼remote后丢凭据、覆盖全局XHR或更改服务端鉴权。
