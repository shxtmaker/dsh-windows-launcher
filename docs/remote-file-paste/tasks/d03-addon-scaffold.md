# D03 · 建立独立附加插件骨架与最小包

轨道：DEV。状态以 `../execution/state.json` 为唯一真值；本任务卡不预置通过结果。

依赖：D00。默认下一建议：D04（仅建议，不在同轮自动执行）。

## 单一目标

得到独立 npm 身份、host/client 双面入口和可验证的最小 tarball。

## 允许改动范围

- `plugins/dsh-remote-attachments/`

## 执行步骤

1. 创建包清单、Cordis patch、类型/构建配置、锁文件及源码目录。
2. 提供真实的 typecheck/build/test:unit 和最小 test:pack；未实现 script 不写成返回成功的空壳。
3. 用测试标记证明 host/client 入口可打包；不声明第二份配对服务，不复制 all 子模块。

## 必须交付

- 可构建的插件骨架、lock、本地 tarball 和入口测试。

## 本任务验收

- tarball 含运行入口和必要资源，不含凭据/生产数据。
- 身份与全家桶、remote 插件不同，未修改聚合清单。
