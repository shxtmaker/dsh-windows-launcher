# D12 · 实现浏览器分块接收与文件构造

轨道：DEV。状态以 `../execution/state.json` 为唯一真值；本任务卡不预置通过结果。

依赖：D03、D10。默认下一建议：D13（仅建议，不在同轮自动执行）。

## 单一目标

将协议消息安全组装成File，兼容HTTP无WebCrypto并限制内存。

## 允许改动范围

- `插件 client receiver`
- `hash/Blob实现`
- `Linux Chromium测试`

## 执行步骤

1. 逐块验证seq/offset/累计大小，接收后ACK，end验证长度和SHA-256。
2. HTTP下使用受控纯JS哈希后备，不依赖安全上下文关闭校验。
3. 测试重放、跨文件污染、恶意大小、取消释放和顺序文件构造。

## 必须交付

- 生产receiver及Chromium真实File字节测试。

## 本任务验收

- File名称/长度/内容正确，坏哈希不能导入。
- 一次只组装规定数量文件，取消回收缓冲。

## 失败与停止条件

不能以模拟对象代替浏览器File，也不能把完整文件Base64塞单消息。
