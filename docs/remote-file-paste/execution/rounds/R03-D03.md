本轮修复的自身缺陷（均在轮内修复并重跑）：
1. 入口布局与 tsc `rootDir` 冲突：`src/index.ts` + `src/client/index.ts` 会产出 `lib/index.js` + `lib/client/index.js`，与清单声明的根级入口不符。改为 `src/host.ts`（`.` 入口）+ `src/client.ts`（`./client` 入口）。
2. `exports` 中 client 类型路径写成 `./lib/types/client/index.d.ts`，实际产物是 `./lib/types/client.d.ts`；同时 P03 判据未归一化 `./` 前缀。两者都已修正，并加强为"声明的入口/类型文件必须真的在包内"。
3. preflight 在 `Set-StrictMode -Version Latest` 下直接读取不存在的 `dependencies` 属性会抛错；改为按属性名存在性判断。
4. 包管理器一度混用 npm 与 pnpm（门禁用 pnpm，本地生成了 `package-lock.json`）。统一为 pnpm 单一锁文件，并在 preflight 中禁止同时保留 npm 锁文件。
5. `npm run test:unit` 原写 `node --test test/unit/`：Node 22 把目录当模块解析而失败；改为 glob `test/unit/**/*.test.mjs`。
