## 本轮修复的自身缺陷（均已修复并重跑）

1. **就绪检测永远超时**：服务日志只在就绪后才写盘，而就绪轮询要读该文件。改为边收边 `appendFile`。
2. **页面恒为 401**：`fetch` 的 `redirect:'follow'` 不会把 303 上的 `Set-Cookie` 带到后续请求。改为手动处理重定向并维护 cookie jar。
3. **合并 bundle 恒为 404**：HTML 属性中 `&rev=` 被转义为 `&amp;rev=`，原先按 `&amp;` 截断导致 URL 丢失 `rev`。改为先整体还原 `&amp;` 再拆分条目。
4. **`down.sh` 归属判断过严导致孤儿进程**：原匹配 `profiles/<name>`，而实际命令行是 `--profile <name>`；结果"拒绝停止"却仍删除目录，留下指向已删除 profile 的孤儿进程。改为"命令行含 profile 名 + `/proc/<pid>/environ` 的 DSH_HOME 指向夹具"双重确认，并在归属无法确认时**拒绝继续清理**；同时增加 pid 文件丢失后的残留清理兜底。
5. pnpm 11 不再读 `package.json` 的 `pnpm` 字段：`allowBuilds` 必须写入 `pnpm-workspace.yaml`，否则 `ERR_PNPM_IGNORED_BUILDS` 会让安装失败。
