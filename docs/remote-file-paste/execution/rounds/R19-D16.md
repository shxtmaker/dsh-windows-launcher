## 2. 验收点

- **手势授权**：真实原生手势（Ctrl+V / Shift+Insert、窗口上下文菜单、拖放）经真实 WPF 事实（窗口可见/前台/焦点在活动页/标签即该目标）才铸造授权；绑定 `targetId + pageEpoch + 焦点令牌`，寿命 2 s（上界 5 s）、**一次性消费、无续期入口**。拒绝码分铸造侧（`gesture-window-hidden/-window-inactive/-focus-outside-page/-tab-not-active`）与校验侧（`-unknown/-replayed/-expired/-not-yet-valid/-target-mismatch/-epoch-mismatch/-focus-mismatch`），且**噪声请求不烧合法授权**。不注册全局键盘钩子：只有判定为原生通路才 `Handled=true`，纯文本/桥模式/拒绝一律放行。
- **不阻塞 STA**：STA 只做有界探测（免打开的格式查询 + `OpenClipboard` 最多 3 次×5 ms 短重试 + 只读 DIB 头 124 字节，不读路径、不复制像素）；`ReadAsync` 立即切线程池并复核剪贴板序号。可恢复码：`clipboard-busy/-open-failed/-changed/-malformed/-timeout`，编排器对读取加 15 s 上界（可注入），超时/失败 → `Abandon` 墓碑。
- **来源优先**：**文件列表恒优先**（即使同时有位图/文本）；纯文本 → 宿主完全不介入、浏览器保留默认粘贴；空/不支持/文件数 0/超上限 → 确定拒绝（复用冻结码）；只有位图时按握手模式（native-paste/bridge，未定则 `consumer-mode-undecided` 拒绝）。
- **唯一消费者**：`NativePasteConsumerLedger` 保证同一动作 `TotalImports ≤ 1`、`ExactlyOneConsumer` 可断言；读取失败/超时立墓碑，桥补导入得 `consumer-bridge-after-native-timeout`；`RefusedDuplicateClaims`/`RefusedBridgeAfterNativeTimeout` 计数被测试钉住（覆盖闸门失败/探测失败/读取失败/超时/重放五条路径）。
- **截图适配**：DIB（BITMAPINFOHEADER/V4/V5、24/32bpp、BI_RGB/BI_BITFIELDS、bottom-up/top-down、行 4 字节对齐）→ RGBA → **确定性 PNG**（固定 IHDR + 单 IDAT + IEND、行滤波 0、固定压缩级别、自带 CRC-32、SHA-256 小写）。**护栏先于分配**：宽高非法 → `screenshot-dimensions-invalid`；>4000 万像素 → `limit-screenshot-pixels`；编码后 >20 MiB → `limit-file-bytes`；不支持的位深/压缩/掩码 → `screenshot-pixel-format-unsupported`；畸形 DIB → `clipboard-malformed`。截图经 `InMemoryNativeCapture`（无线程/无路径）进 D14 真实暂存服务。
- **不信任页面**：页面既不能铸造/续期授权，也不能提供路径；页面提供的 `isTrusted` 与本机路径都不参与判定（结构性：候选只能来自原生手势绑定的捕获票据）。

## 5. 未验项与开放风险

1. **Windows 实机事实**全部未验：CF_DIB 句柄生命周期、`GlobalUnlock` 归零返回值、`GlobalSize` vs `biSizeImage`、剪贴板占用错误码、真实 STA 焦点表现、WPF `DataObject` 能否强转为 COM `IDataObject`（若不能，拖放会得确定的 `drop-no-file-list`，需改走 `DataFormats.FileDrop` 的同一内部登记口——**那会削弱"公开 API 不收路径"的强度，必须先登记再改**）、`AllowExternalDrop=false` 是否真让外部拖放落到 WPF。
2. **握手解析未接**：`capabilities`→截图所有者、`context`→composer 上下文的真实解析与送达属 D17；D16 只交付规则与 `RemoteWindow.ReportScreenshotHandshake/ReportComposerContext` 接入点。在此之前**只有位图粘贴**会以 `consumer-mode-undecided` 被确定拒绝，文件列表/拖放不受影响。
3. **Acceptance 程序集无法在 Linux 枚举**（缺 `Microsoft.WindowsDesktop.App`），其新增 6 条哈希由"完全限定名"推导（已用 45/45 冻结基线全命中验证该推导）；这不是 MTP 实枚举，已登记为不确定项。D14 已知的 4 条反斜杠理论用例隐患按规则未动。
