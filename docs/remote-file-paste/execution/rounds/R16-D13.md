## 2. 中途未通过项如何解除

**G08-remote-degraded-unavailable** 起初未过：remote 通道缺失时附件能力没有明确报不可用。补上判定后转绿，并新增了配套证据：

- **降级夹具**：新增 profile `dsh-attachments-degraded`（端口 3098，remote 仍 enabled 但 `requirePairingForLan:false` ⇒ 不注入 `/remote` 改写层；仅该 profile 放行 LAN trustedHosts，使裸 `/api` 实际可达）。选择它而不是 `enabled:false`，是因为后者会连 remote 自己的配对路由一起关掉，无法同时断言"配对未被关闭"。
- **承载主动拒绝且零请求**：非 loopback 且无改写层时承载直接拒绝（`capability-disabled`），CDP 观测上传请求数 **0**；**对照组健康页同一探针确实发出改写后的 `/remote/api/session/uploadFileBinary`**（N9）——证明"零请求"不是恒真。
- **配对不受影响**：冲突页与降级页在同一时刻断言 `POST /api/pair/heartbeat`=200、`/remote/api/session/list`=200、会话数一致；且从不调用 remote seat 的 `restore`、不删改其字段（单测用抛异常的 restore 守着）。
