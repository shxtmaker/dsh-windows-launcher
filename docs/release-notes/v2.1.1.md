## 已知问题（沿用 2.1.0）

1. `DshLauncher.Platform.Windows.Tests` 的 4 条含反斜杠参数理论用例在真实 Windows XML 门禁下会因 MTP
   双重转义报 `missing/unexpected`（基线来自枚举 JSON 归一值）；Windows 轨道 W00 必须先重新推导或统一归一。
2. `Session.promptError` 公开路径存在（插件 `ctx.sessions.scope(id)` → `sessionOf(scope)` → `getSnapshot().promptError`）；
   当前黑盒测试没有插件上下文句柄，不得表述为"没有公开接口"。
3. 撤销证据只表述为"请求到达 Host 前被门控拒绝"（403 + `unpaired`），不得扩展为"已通过鉴权的上传流被主动终止"。
