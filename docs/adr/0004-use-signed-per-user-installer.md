# 以签名的按用户安装包交付 Windows 启动器

V1 只发布一个受信任签名的 Inno Setup 按用户 EXE 安装包，应用采用 `win-x64` .NET 10 自包含发布并使用共享 Evergreen WebView2 Runtime；安装包携带离线 Runtime 前置，可在首次安装时选择合格的本地固定卷目录。这样以一个受支持的安装身份覆盖标准用户、离线部署、运行时修复、就地升级、卸载和签名验证，同时让目标配置与浏览器会话始终独立于程序位置。

## Considered Options

- 便携 ZIP：复制即可运行，但会引入第二套程序定位、Runtime 修复、升级、卸载和验收路径，也难以建立唯一受支持的安装身份。
- MSIX：安装身份和更新模型更强，但会增加打包、签名和 Windows 部署约束，且不能简化当前 WebView2、离线前置和 Windows 10 尽力兼容目标。
- 传统按用户 EXE：无需管理员权限，可保留成熟的 Win32 与 WebView2 宿主能力，并能显式控制离线前置、签名、修复和数据保留边界。

## Consequences

项目必须维护稳定 `AppId`、签名与时间戳流水线、完整离线安装包和真实安装升级矩阵。自定义程序目录只允许本地固定卷，升级与修复不能迁移既有目录；程序位置变化只能通过保留数据的卸载后重装完成。V1 不提供便携版、MSIX、后台更新器或双版本自动回滚，自包含 .NET 安全补丁必须随新的完整签名安装包发布。
